## What I Ended Up With
A private Git server that looks and works much like GitHub. I keep my homelab configuration, scripts and small projects there, with issues and pull requests when I want them, and mirrors of a few public repositories.

## Why I Chose Gitea

GitLab does far more than I need and wants a lot of memory. Gitea is a single Go program that runs comfortably on small hardware, and its interface is familiar to anyone who has used GitHub.

## How I Set It Up

### 1. Compose File
I used the SQLite example from the Docker install guide. For one person it is plenty, and it avoids running a separate database.

### 2. Installer
On first visit Gitea shows an install page. I kept the defaults, set the site name, and created the admin account there.

### 3. First Repositories
I turned off open registration, pushed my homelab config repository, and added a mirror of a GitHub project I follow.
