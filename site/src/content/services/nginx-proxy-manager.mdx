## What I Ended Up With
One front door for my apps. Instead of remembering a different address for each service, every app has a readable name, and the proxy forwards each request to the right container with a valid HTTPS certificate.

## Why I Chose Nginx Proxy Manager

Nginx is powerful but its config files are easy to get wrong when you are starting out. Nginx Proxy Manager puts the common jobs in a web form: add a host, point it at an app, tick a box for HTTPS. Certificates renew on their own.

## How I Set It Up

### 1. Starting the Stack
The repo's Cloudflare option runs Nginx Proxy Manager on its own. I followed its guide, filled in the environment file, and started it:

```bash
cd stacks/networking/option-b-cloudflare
docker compose up -d
```

### 2. First Login
I opened the admin interface, signed in, and replaced the default admin account with my own email and a strong password.

### 3. First Proxy Host
I added a proxy host with a name for one app, set the destination to the app's container name or `YOUR_SERVER_IP`, and requested a certificate on the SSL tab. Once that worked I repeated it for the other apps.
