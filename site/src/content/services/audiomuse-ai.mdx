## What I Ended Up With
A service that listens to my music library on my own server and groups songs by how they actually sound, not by genre tags. It creates playlists of similar tracks, finds songs that sound like one I pick, and pushes the results back to my music server so they show up in every player.

## Why I Chose AudioMuse AI

My library has plenty of songs with messy or missing tags, so tag-based smart playlists were hit and miss. AudioMuse AI works from the audio itself, which is the closest thing I have found to a streaming service's radio feature without sending my listening data anywhere.

## How I Set It Up

### 1. Checking the Hardware
Before anything else I read the requirements in the README. The analysis models need AVX2 on Intel or AMD CPUs, and the project lists a minimum amount of RAM and recommends fast storage.

### 2. Deploying the Containers
I used the project's Docker Compose example, filled in my music server's address and the credentials the README asks for, and started the stack. It runs a web front end, a worker that does the heavy lifting, and PostgreSQL.

### 3. First Analysis
In the web interface I started an analysis run and left it alone. Once it finished, I ran clustering to create the first set of playlists, then tried the similar-song search on a few favourites.
