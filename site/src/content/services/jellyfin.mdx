## How I Set It Up

### 1. Storage & Environment Setup
I verified that my host machine had `/data/media` created. I placed a test video file inside `/data/media/movies` so Jellyfin had something to index right away.

```bash
# I verified my UID and GID matched my stacks/.env file
id -u
id -g
```

### 2. Launching the Container
I navigated to the `media-server/` directory inside `stacks/` and launched the stack:

```bash
cd stacks/media-server
docker compose up -d
```

### 3. First-Time UI Setup Walkthrough
Once running, I opened my web browser to `http://YOUR_SERVER_IP:8096` and followed these 6 straightforward steps:

1. **Language Selection:** I chose **English** and clicked **Next**.
2. **Admin Account Creation:** I entered my preferred admin username and a strong password.
3. **Add Media Libraries:** I clicked **+ Add Media Library**:
   - **Content type:** I selected `Movies`.
   - **Folders:** I clicked `+` and chose `/data/media/movies` (or `/data/media`).
   - I clicked **OK** and then **Next**.
4. **Metadata Settings:** I left preferred language and country at defaults so Jellyfin automatically fetched movie posters, ratings, and plot summaries from TMDB.
5. **Remote Access:** I left **Allow remote connections to this server** checked. I clicked **Next**, then **Finish**.
6. I signed in with my new credentials and started streaming.
