## What I Ended Up With
A clean web page that shows the contents of a folder on my server. I can upload a file from my phone, rename or move things, edit a text file, and make a share link, all without opening a terminal or an SFTP app.

## Why I Chose File Browser

Nextcloud is great for syncing, but it is a lot of software when I only want to drop a file into a folder. File Browser is a single small container with almost no setup, and it works on any device with a browser.

## How I Set It Up

### 1. Choosing the Folder
I mounted a single data folder into the container rather than the whole drive. File Browser can only see what you mount, which is the simplest way to limit what it can touch.

### 2. First Login
I opened the web interface and signed in with the first-run credentials from the docs, then changed the admin password straight away.

### 3. Users and Shares
I created a separate account for each person with its own folder scope and turned off permissions they did not need, such as running commands.
