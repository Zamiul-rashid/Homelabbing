## What I Ended Up With
A web page with every PDF tool I need: merge, split, rotate, reorder pages, compress, convert to and from other formats, add a watermark, sign, and run OCR. The files are processed on my server and never go to an outside website.

## Why I Chose Stirling PDF

Free online PDF sites want you to upload your documents to them, and many of those documents are personal: contracts, IDs, bank statements. Stirling PDF gives me the same tools in one container that only I control.

## How I Set It Up

### 1. Picking a Variant
I read the install page, chose the variant that includes the tools I wanted, and copied the Compose example from the docs.

### 2. First Use
I opened the web interface, dragged in two PDFs, and merged them. Every tool works the same way: pick it, add files, set options, download the result.

### 3. Locking It Down
Since anyone on the home network could open it, I turned on the built-in login.
