## What I Ended Up With
One browser tab with a list of every container and its log streaming live. When an app misbehaves, I open Dozzle, click the container, and search for the error, without logging into the server.

## Why I Chose Dozzle

Most of my troubleshooting starts with "what do the logs say?". Dozzle does exactly that and nothing else. It is tiny, it does not store logs anywhere, and it reads them straight from Docker as they are written.

## How I Set It Up

### 1. Starting It
I ran the official image with the Docker socket mounted read-only, following the getting-started guide.

### 2. Using It
I opened the web interface, which lists every container. Clicking one starts a live log stream; the search box filters it as I type.

### 3. Locking It Down
Logs can contain sensitive details, so I turned on Dozzle's simple user authentication.
