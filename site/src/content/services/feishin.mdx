## What I Ended Up With
A music player on my computer that feels like a streaming app but plays my own library from Navidrome. It shows album art, queues, playlists and lyrics, and it sends plays back to the server so my listening history stays in one place.

## Why I Chose Feishin

Navidrome's built-in web player works, but it is basic. Feishin is a rewrite of the older Sonixd player and is built for long listening sessions on a desktop. It talks to Navidrome, Jellyfin and other servers that speak the OpenSubsonic API, so I did not have to change anything on the server side.

## How I Set It Up

### 1. Picking a Version
I installed the desktop build on my computer. If you would rather use a browser, the README explains how to run the web version as a container next to your other apps.

### 2. Connecting to the Server
On first launch Feishin asks for a server. I chose **Navidrome**, entered the same address I use for Navidrome in the browser, and signed in with my normal Navidrome account. My library loaded straight away.

### 3. Small Tweaks
I turned on lyrics and checked that scrobbling was enabled, so plays from Feishin count the same as plays from my phone.
