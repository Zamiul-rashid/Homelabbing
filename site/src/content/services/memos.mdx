## What I Ended Up With
A private place for quick thoughts, links and to-dos. Each note is a short Markdown post on a timeline, like a microblog only I can read. Tags and search make old notes easy to find again.

## Why I Chose Memos

I wanted something faster than a full notes app for small things I would otherwise lose. Memos opens straight to a text box, and it runs as one small container with a SQLite database by default.

## How I Set It Up

### 1. Starting the Container
I ran the official image with a volume for its data folder, following the install docs.

### 2. First Account
I opened the web interface and created my account. The first user becomes the admin, so I did this right after starting it. I then turned off open sign-ups in the settings.

### 3. Daily Use
I added Memos to my phone's home screen. Writing a note is now one tap and a few words, and a #tag at the end keeps things grouped.
