## What I Ended Up With
A web library of the games I own, with box art, descriptions and release details for each one. Many older systems play straight in the browser, and save files can follow me between devices.

## Why I Chose RomM

My ROMs were a pile of folders with cryptic file names. RomM turns that into something I can browse like a shop front, and it does it from the files I already have instead of a separate launcher on each computer.

## How I Set It Up

### 1. Organising the Files
I followed the folder layout in the docs: one folder per platform, named the way RomM expects. This step took longer than the install itself.

### 2. Metadata Keys
I registered for API access with the metadata providers I wanted and put the keys into the environment file from the official Compose example.

### 3. Starting and Scanning
I started the stack, opened the web interface, created my admin account, and ran a scan. RomM matched most games automatically; I fixed the few it missed by hand.
