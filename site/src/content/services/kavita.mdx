## How I Set It Up

### 1. Launching the Container
Once my books and comics were placed in `/data/media/books` and `/data/media/comics`, I ran `docker compose up -d` in `stacks/book-reader/`:
```bash
cd stacks/book-reader
docker compose up -d
```

### 2. Creating My Admin Account
I opened `http://YOUR_SERVER_IP:5000` in my web browser. I was greeted by the initial setup screen where I created my admin profile username and password.

### 3. Adding My Libraries
1. In the Kavita dashboard, I clicked **Server Settings (Gear icon)** → **Libraries** → **+ Add Library**.
2. **Name:** I entered `Books` or `Comics`.
3. **Type:** I chose `Book` for novels/EPUBs, or `Comic/Manga` for CBZ/CBR archives.
4. **Folders:** I browsed to `/data/media/books` (or `/data/media/comics`), selected the folder, and clicked **Save**.
5. Kavita performed a lightning-fast background scan and built my digital bookshelf!
