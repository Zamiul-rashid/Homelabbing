## Multi-Container Architecture

Immich relied on a microservice stack that my `stacks/photo-backup/docker-compose.yml` configured automatically:

- **`immich-server` (`:2283`)** — Core API, web frontend, and upload controller.
- **`immich-machine-learning`** — Python service running CLIP and face detection models locally.
- **`immich-redis`** — High-speed task queue and job caching.
- **`immich-db` (`pgvecto-rs`)** — PostgreSQL database with vector search capabilities for instant semantic photo lookups.

## How I Set It Up

### 1. Launching the Stack
I navigated to `stacks/photo-backup/` and started the containers:
```bash
cd stacks/photo-backup
docker compose up -d
```

### 2. First-Time Registration
I navigated to `http://YOUR_SERVER_IP:2283` and clicked **Get Started**. I entered my email, full name, and password to create my initial admin account.

### 3. Connecting the Mobile App
1. I downloaded **Immich** from my phone's App Store.
2. I opened the app and entered my server address: `http://YOUR_SERVER_IP:2283` (or my remote HTTPS URL).
3. I logged in and toggled on **Foreground & Background Backup**. I watched as my phone backed up thousands of photos at lightning speed over my local Wi-Fi.
