## What I Ended Up With
Dashboards that show CPU, memory, disk and network use for my server over time, plus metrics from the apps that publish them. When something feels slow, I can look back and see what changed and when.

## Why I Chose Grafana and Prometheus

Uptime checks tell me whether an app answers. They do not tell me that a disk is slowly filling or that one container is eating memory. Prometheus and Grafana are the standard open-source pair for this, and almost every app or device has an exporter for them.

## How I Set It Up

### 1. Prometheus
I wrote a small config file with a scrape job for Prometheus itself and one for node_exporter on the host, then started both containers. The targets page in Prometheus showed both as up.

### 2. Grafana
I started Grafana, added Prometheus as a data source using its container name, and imported a community dashboard for node_exporter. Graphs appeared straight away.

### 3. More Targets and Alerts
Over time I added exporters for the apps that support them and a few alert rules. I kept the rules few, so an alert always means something.
