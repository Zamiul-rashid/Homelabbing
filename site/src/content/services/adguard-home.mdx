## What I Ended Up With
I built a local DNS server that intercepted domain requests before they ever reached the internet. By checking incoming DNS queries against blocklists, AdGuard Home stopped ads, trackers, and malware across every iPhone, Android, smart TV, tablet, and PC on my home Wi-Fi automatically.

## Why I Chose AdGuard Home

While browser extensions like uBlock Origin worked wonders on my desktop computers, they couldn't protect my smart TVs, IoT gadgets, streaming devices, or mobile applications. AdGuard Home operated at the network level as the DNS server, blocking tracking telemetry before pages even loaded and cutting my page-load times measurably.

## How I Set It Up

### 1. Launching the Container
I navigated to the `home-automation` stack directory and launched the stack:
```bash
cd stacks/home-automation
docker compose up -d
```

### 2. First-Run Setup Wizard
I opened AdGuard Home's setup wizard in my browser (the address is in the stack's README):
1. Under **Admin Web Interface** and **DNS Server**, I kept the listen settings that match the Compose file. The stack's README explains them.
2. I set the DNS server to listen on all interfaces so every device on the network could reach it.
3. I created my administrative username and a secure password, then finished the wizard and opened the dashboard.

### 3. Pointing My Router to AdGuard Home
To protect my entire household:
1. I logged into my home router's admin panel (the address is usually printed on a sticker on the router).
2. I navigated to **LAN / DHCP Server Configuration**.
3. I replaced my ISP's default Primary DNS Server with my home server's IP (`YOUR_SERVER_IP`).
4. I saved the settings and reconnected my phone to Wi-Fi. Checking my AdGuard Home dashboard, I could see live DNS queries being filtered immediately.
