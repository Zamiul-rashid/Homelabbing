## How I Set It Up

### 1. Launching the Container
I navigated to the `home-automation` stack directory and launched the stack:
```bash
cd stacks/home-automation
docker compose up -d
```

### 2. First-Run Setup Wizard (`Port 3000`)
I opened `http://YOUR_SERVER_IP:3000` in my web browser to enter AdGuard Home's initial setup wizard:
1. Under **Admin Web Interface**, I set the listen port to `80` (which mapped externally to `8083` in my `docker-compose.yml`).
2. Under **DNS Server**, I ensured it listened on All Interfaces (`0.0.0.0`) on Port `53`.
3. I created my administrative username and a secure password, then finished the wizard. My permanent admin dashboard was then live at `http://YOUR_SERVER_IP:8083`.

### 3. Pointing My Router to AdGuard Home
To protect my entire household:
1. I logged into my home router's admin panel (typically `192.168.1.1` or `192.168.0.1`).
2. I navigated to **LAN / DHCP Server Configuration**.
3. I replaced my ISP's default Primary DNS Server with my home server's IP (`YOUR_SERVER_IP`).
4. I saved the settings and reconnected my phone to Wi-Fi. Checking my AdGuard Home dashboard, I could see live DNS queries being filtered immediately.
