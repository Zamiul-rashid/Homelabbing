## What I Ended Up With
My phone and laptop can reach my home server from anywhere as if they were on the home Wi-Fi. Nothing on my router is opened to the internet for it: devices find each other through Tailscale and talk over encrypted WireGuard connections.

## Why I Chose Tailscale

Opening apps to the whole internet means every bot can try to log in. Running my own VPN server meant certificates, config files and router changes. Tailscale needed an account, an app on each device, and a few minutes.

## How I Set It Up

### 1. Devices First
I made an account and installed Tailscale on my phone and laptop, signing in on each.

### 2. The Server
In the admin console I generated an auth key, put it in the environment file, and started the stack:

```bash
cd stacks/networking/option-d-tailscale
docker compose up -d
```

### 3. Checking It
The server showed up in the device list within a few seconds. With Wi-Fi turned off on my phone, I opened an app through Tailscale to confirm it worked over mobile data.
