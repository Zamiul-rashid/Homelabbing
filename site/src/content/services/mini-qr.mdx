## What I Ended Up With
A small QR code tool on my own server. I type a link, Wi-Fi details or contact info, pick colours and a style, maybe add a logo, and download the result. It can also scan a QR code from the camera or from an image.

## Why I Chose Mini QR

Most free QR sites are covered in ads, and some create "dynamic" codes that send people through their own redirect service. Mini QR makes plain codes that point straight at your data, and it is a static web app, so it is tiny to host.

## How I Set It Up

### 1. Running It
I followed the self-hosting guide from the repository and started it with Docker Compose. There is no database and nothing to configure for basic use.

### 2. First Code
I made a Wi-Fi code for guests using the Wi-Fi template, picked a preset style, and exported it as SVG so it prints sharply at any size.
