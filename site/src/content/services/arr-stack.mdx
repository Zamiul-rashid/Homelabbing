## What I Ended Up With
I built an automated media pipeline. When I browsed and requested a movie or TV show on **Seerr** (formerly Jellyseerr), it triggered search indexers in **Prowlarr**, sent the optimal quality torrent to **qBittorrent**, and monitored progress in **Radarr/Sonarr**. Radarr then renamed and moved the finished file into `/data/media`, where Jellyfin picked it up immediately.

## Why I Used the *arr Suite

I was completely done hunting down torrents on sketchy websites, manually unzipping files, fixing confusing file names like `Movie.2023.1080p.WEB-DL.x264.AC3-EVO.mkv`, and dragging them across folders.

## The 5 Synchronized Containers

Running this stack launched five specialized tools inside `stacks/arr-stack/`, each with a distinct job:

1. **qBittorrent**: High-performance download engine with web interface and hardlink support.
2. **Prowlarr**: Indexer manager that synced search providers directly to Radarr and Sonarr.
3. **Radarr**: Movie monitoring, searching, downloading, and automated renaming.
4. **Sonarr**: TV show and anime monitoring with season/episode tracking.
5. **Seerr** (formerly Jellyseerr): Request portal where family and friends could discover and request content.

## How I Configured It

### 1. Launching the Stack
I navigated to `stacks/arr-stack/` and started all 5 containers:
```bash
cd stacks/arr-stack
docker compose up -d
```

### 2. Connecting Prowlarr
Each app has its own web interface; the addresses are in the stack's README.
1. I clicked **Add Indexer**, searched for the indexers I wanted, and clicked **Save**.
2. I went to **Settings → Apps → + Add**:
   - Added **Radarr** (by its container name, `radarr`, as the README shows) and pasted my Radarr API key (found in Radarr under Settings → General).
   - Added **Sonarr** (container name `sonarr`) and pasted my Sonarr API key.
3. I clicked **Sync App Indexers**: my search providers were automatically linked.

### 3. Linking Radarr & Sonarr to qBittorrent
In both Radarr and Sonarr:
1. I went to **Settings → Download Clients → + Add → qBittorrent**:
   - **Host:** `qbittorrent` (the container name; the rest of the connection details are in the stack's README)
2. I clicked **Test** and **Save**.

### 4. Connecting Seerr
1. I opened the Seerr dashboard and logged in using my Jellyfin account, pointing it at the Jellyfin container by name.
2. I added my Radarr and Sonarr servers (again by container name) using their API keys. Then I was ready to request.
