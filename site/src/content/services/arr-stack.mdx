## What I Ended Up With
I built an automated media pipeline. When I browsed and requested a movie or TV show on **Jellyseerr**, it triggered search indexers in **Prowlarr**, sent the optimal quality torrent to **qBittorrent**, and monitored progress in **Radarr/Sonarr**. Radarr then renamed and moved the finished file into `/data/media`, where Jellyfin picked it up immediately.

## The 5 Synchronized Containers

Running this stack launched five specialized tools inside `stacks/arr-stack/`, each with a distinct job:

1. **qBittorrent (`:8080`)** — High-performance download engine with web interface and hardlink support.
2. **Prowlarr (`:9696`)** — Indexer manager that synced search providers directly to Radarr and Sonarr.
3. **Radarr (`:7878`)** — Movie monitoring, searching, downloading, and automated renaming.
4. **Sonarr (`:8989`)** — TV show and anime monitoring with season/episode tracking.
5. **Jellyseerr (`:5055`)** — Request portal where family and friends could discover and request content.

---

## How I Configured It

### 1. Launching the Stack
I navigated to `stacks/arr-stack/` and started all 5 containers:
```bash
cd stacks/arr-stack
docker compose up -d
```

### 2. Connecting Prowlarr (`http://YOUR_IP:9696`)
1. I clicked **Add Indexer**, searched for public indexers (e.g., `1337x`, `EZTV`), and clicked **Save**.
2. I went to **Settings → Apps → + Add**:
   - Added **Radarr** (`http://radarr:7878`) and pasted my Radarr API key (found in Radarr under Settings → General).
   - Added **Sonarr** (`http://sonarr:8989`) and pasted my Sonarr API key.
3. I clicked **Sync App Indexers** — my search providers were automatically linked.

### 3. Linking Radarr & Sonarr to qBittorrent
In both Radarr (`http://YOUR_IP:7878`) and Sonarr (`http://YOUR_IP:8989`):
1. I went to **Settings → Download Clients → + Add → qBittorrent**:
   - **Host:** `qbittorrent`
   - **Port:** `8080`
2. I clicked **Test** and **Save**.

### 4. Connecting Jellyseerr (`http://YOUR_IP:5055`)
1. I opened the Jellyseerr dashboard and logged in using my Jellyfin account (`http://jellyfin:8096`).
2. I added my Radarr (`http://radarr:7878`) and Sonarr (`http://sonarr:8989`) endpoints using their API keys. Then I was ready to request.
