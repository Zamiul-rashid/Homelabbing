## What I Ended Up With
A searchable archive of my paperwork. I scan a letter or save a PDF bill into a folder, and a few moments later it is in Paperless-ngx with its text recognised, a date, a sender and tags. Finding a receipt now takes a search box instead of a drawer.

## Why I Chose Paperless-ngx

I kept losing paper I later needed, and scans dumped into folders were not much better because I could not search them. Paperless-ngx runs OCR on everything, keeps the original file, and learns from how I tag documents so new ones are filed for me.

## How I Set It Up

### 1. Choosing a Compose File
The project publishes several Compose files. I used one with PostgreSQL and the optional Tika and Gotenberg containers, so Word and email files are handled as well as PDFs.

### 2. Configuration
In the environment file I set my OCR language, time zone and a long random secret key. Then I started the stack and created the admin user.

### 3. The Consume Folder
Anything placed in the consume folder is imported and then removed from it. I pointed my scanner's "scan to folder" option there, so scanning a page is all it takes to file it.
