## What I Ended Up With
A password manager that works exactly like Bitwarden on my phone, laptop and browser, but stores the encrypted vault on my own server. The official Bitwarden apps and extensions connect to it once I enter my server's address.

## Why I Chose Vaultwarden

The official Bitwarden server is a set of heavier containers built for organisations. Vaultwarden is an unofficial, community-written server in Rust that implements the same API in a single small container. It is not affiliated with Bitwarden, but it works with their clients.

## How I Set It Up

### 1. HTTPS First
I set up a reverse proxy with a valid certificate before starting Vaultwarden, because browsers block the vault's encryption features on plain HTTP.

### 2. Starting It
I ran the official image with a data volume, created my account in the web vault, then set `SIGNUPS_ALLOWED=false` and restarted the container so nobody else could register.

### 3. Connecting Clients
In each Bitwarden app I chose the self-hosted option, entered my server's address, and signed in. My vault synced to every device.
